# Utah

**Utah** (_Utahraptor ostrommaysi_) is Bluefin built on [Fedora Hummingbird](https://fedoramagazine.org/fedora-hummingbird-linux-taking-the-hummingbird-model-to-the-full-os/), which provides a hardened, fast-moving bootable base without a desktop. Utah adds the desktop layer: Bluefin's GNOME desktop and user experience. Stack built from verified upstream sources via `projectbluefin/utah-packages`.

:::info[Pre-alpha]
Utah is an alpha build in active development. Its `:testing` container image is published on GHCR. Track progress and file issues at [projectbluefin/utah](https://github.com/projectbluefin/utah/issues).
:::

## Architecture

Utah is composed across two coordinated repositories:

| Repository                                                                        | Role                                                                                             |
| --------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------ |
| [`projectbluefin/utah`](https://github.com/projectbluefin/utah)                   | Composes the bootc OS image with Bluefin's package contract and desktop services.                |
| [`projectbluefin/utah-packages`](https://github.com/projectbluefin/utah-packages) | Builds GNOME 51 and the desktop stack from verified upstream sources, published as an OCI layer. |

## Image Streams

Utah defines four flavors matching Bluefin's standard targets: `utah`, `utah-nvidia`, `utah-gaming`, and `utah-nvidia-gaming`.

| Tag        | Stream  | Availability                                |
| ---------- | ------- | ------------------------------------------- |
| `:stable`  | Stable  | `ghcr.io/projectbluefin/utah:stable`        |
| `:testing` | Testing | `ghcr.io/projectbluefin/utah:testing`       |

## Features and Stack

- **Kernel**: Same kernel options as Bluefin, Open Gaming Collective (OGC) Linux kernel available with Gaming mode
- **Desktop**: GNOME 51 stack assembled from upstream source via `utah-packages`.
- **NVIDIA and Gaming**: Specialized flavors include NVIDIA drivers and gaming stack components.
