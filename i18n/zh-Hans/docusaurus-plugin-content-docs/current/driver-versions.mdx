# 驱动版本

有时 raptor 就是会缠上你。本页追踪 Bluefin 各版本 major 驱动版本，帮助用户识别并切换到特定的驱动版本。适合用来排查主要组件。如果你想知道问题是否已被修复，稍后请使用 `ujust rebase-helper` rebased 回发布流。祝你好运，你可以的。

下方显示的版本来自所选流的镜像 SBOM。缺失的 SBOM 显示为不可用；没有已发布镜像标签的归档 SBOM 快照无法 rebased 到。

在运行上方可用的镜像切换命令后，重启以激活部署：

```bash
sudo systemctl reboot
```
