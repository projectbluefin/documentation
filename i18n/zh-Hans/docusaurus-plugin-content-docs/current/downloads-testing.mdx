## 使用校验和验证下载

**校验和**可用于验证下载是否成功完成，以及文件是否损坏或被篡改。下载 ISO 后，可以将其校验和与官方校验和文件进行比较，以确保文件完整。此步骤虽为可选，但对于重要的安装，建议进行验证。

#### 如何使用 sha256sum 验证校验和

1. **下载 ISO 文件及其对应的 CHECKSUM 文件**
   - 例如：`bluefin-stable-x86_64.iso` 和 `bluefin-stable-x86_64.iso-CHECKSUM`

2. **生成已下载 ISO 的校验和：**

   ```bash
   sha256sum bluefin-stable-x86_64.iso
   ```

3. **对照官方校验和文件进行验证：**

   ```bash
   sha256sum -c bluefin-stable-x86_64.iso-CHECKSUM --ignore-missing
   ```

4. **确认结果：** 查看 ISO 文件对应的输出中是否有 `OK`。

**示例：**

```bash
# Generate checksum of downloaded file
$ sha256sum bluefin-stable-x86_64.iso
a1b2c3d4e5f6789012345678901234567890abcdef1234567890abcdef123456  bluefin-stable-x86_64.iso

# Verify against official checksum file
$ sha256sum -c bluefin-stable-x86_64.iso-CHECKSUM --ignore-missing
bluefin-stable-x86_64.iso: OK

# 🦖 Rawr! Your download is verified
```

## 配置并使用安装程序的问题报告功能

1. 安装前，启用 `ujust report`：
   - 将正在运行的 Live 系统连接到网络。
   - 打开 Firefox 并登录 GitHub。
   - 打开终端并执行 `brew install gh`。
   - 在命令行中执行身份验证：`gh auth login`。选择通过浏览器验证。
2. 安装失败后：
   - 使用截图工具截取相关画面。
   - 在终端中执行 `ujust report`。报告完成后，按 `ESC` 结束。
   - 浏览器应会自动打开相应仓库的新建问题页面，填写即可。
