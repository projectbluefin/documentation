## Verificação de downloads com somas de verificação

As **somas de verificação** permitem confirmar que o download foi concluído com sucesso e que o arquivo não foi corrompido nem adulterado. Após baixar uma ISO, você pode comparar sua soma de verificação com o arquivo oficial de somas de verificação para garantir a integridade. Embora opcional, a verificação é recomendada para instalações importantes.

#### Como conferir somas de verificação usando sha256sum

1. **Baixe o arquivo ISO e o arquivo CHECKSUM correspondente**
   - Por exemplo: `bluefin-stable-x86_64.iso` e `bluefin-stable-x86_64.iso-CHECKSUM`

2. **Gere a soma de verificação da ISO baixada:**

   ```bash
   sha256sum bluefin-stable-x86_64.iso
   ```

3. **Verifique usando o arquivo oficial de somas de verificação:**

   ```bash
   sha256sum -c bluefin-stable-x86_64.iso-CHECKSUM
   ```

4. **Confirme o resultado:** Você deverá ver `bluefin-stable-x86_64.iso: OK`. Se a verificação falhar, baixe a ISO novamente.

**Exemplo:**

```bash
# Generate checksum of downloaded file
$ sha256sum bluefin-stable-x86_64.iso
a1b2c3d4e5f6789012345678901234567890abcdef1234567890abcdef123456  bluefin-stable-x86_64.iso

# Verify against official checksum file
$ sha256sum -c bluefin-stable-x86_64.iso-CHECKSUM
bluefin-stable-x86_64.iso: OK

# 🦖 Rawr! Your download is verified
```
