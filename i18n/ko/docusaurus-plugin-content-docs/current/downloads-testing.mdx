## 체크섬으로 다운로드 확인

**체크섬(checksum)**은 다운로드가 성공적으로 완료되었고 손상되거나 변조되지 않았음을 확인하게 해줍니다. ISO를 다운로드한 후 공식 체크섬 파일과 비교하여 무결성을 확인할 수 있습니다. 선택적이지만, 중요한 설치에는 확인이 권장됩니다.

#### sha256sum으로 체크섬 확인 방법

1. **ISO 파일과 해당 CHECKSUM 파일과 다운로드하기**
   - 예: `bluefin-stable-x86_64.iso` 및 `bluefin-stable-x86_64.iso-CHECKSUM`

2. **다운로드한 ISO의 체크섬 생성하기:**

   ```bash
   sha256sum bluefin-stable-x86_64.iso
   ```

3. **공식 체크섬 파일과 비교하기:**

   ```bash
   sha256sum -c bluefin-stable-x86_64.iso-CHECKSUM --ignore-missing
   ```

4. **결과 확인하기:** ISO 파일에 대한 출력에서 `OK`을 찾으세요.

**예시:**

```bash
# 다운로드한 파일의 체크섬 생성
$ sha256sum bluefin-stable-x86_64.iso
a1b2c3d4e5f6789012345678901234567890abcdef1234567890abcdef123456  bluefin-stable-x86_64.iso

# 공식 체크섬 파일과 비교
$ sha256sum -c bluefin-stable-x86_64.iso-CHECKSUM --ignore-missing
bluefin-stable-x86_64.iso: OK

# 🦖 Rawr! 다운로드가 확인되었습니다
```

## Installer 버그 보고 설정 및 실행

1. 설치하기 전 - `ujust report` 활성화:
   - 실행 중인 라이브 시스템을 네트워크에 연결합니다.
   - Firefox를 열고 로그인합니다.
   - 터미널을 열고 `brew install gh`를 실행합니다.
   - 명령줄 인증을 수행합니다: `gh auth login`. 브라우저 방법을 사용하세요.
2. 실패한 설치 이후:
   - Screenshot 도구로 관련 스크린샷을 캡처합니다.
   - 터미널에서 `ujust report`를 실행합니다. 보고서가 완료되면 `ESC`로 종료합니다.
   - 브라우저가 자동으로 적절한 repo의 새 이슈를 열어야 합니다. 채우기만 하면 됩니다.
