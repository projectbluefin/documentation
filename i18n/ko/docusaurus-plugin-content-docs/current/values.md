[쿠버네티스 커뮤니티 가치](https://www.kubernetes.dev/community/values/)에서 파생되었지만 좀 더 동네 같은 느낌으로:

## 중앙 집중보다 분산이 낫다

분산된 비동기 소유권, 협업, 소통, 의사 결정.

## 프로세스보다 자동화

프로젝트는 반복적인 작업을 자동화하는 데 드는 시간을 수고(토일)보다 더 가치 있게 여깁니다.

## 배타보다 포용이 낫다

폭넓게 성공하고 유용한 기술은 다양한 관점과 기술 역량을 필요로 하며, 이는 환영하고 존중하는 환경에서만 들을 수 있습니다. 우리 커뮤니티는 논의에 쏟은 시간과 노력을 존중합니다.

## 정체보다 진화가 낫다

새로운 아이디어에 대한 열린 태도와 숙고된 기술적 진화가 우리 프로젝트를 더 강하게 만듭니다.

## 투명성

프로젝트는 사용자가 이 이미지들을 빌드하는 데 사용된 프로세스를 검증할 수 있도록 최신 오픈 소스 기술([sigstore](https://www.sigstore.dev/) 등)을 활용하고자 노력합니다. 프로젝트는 가능한 한 많은 데이터를 공유하여 사용자를 교육하고자 합니다.

## 행동 우선

프로젝트는 안정성과 정확성을 선호하지만, 문제를 신속하고 효율적으로 해결하기 위해 행동해야 함을 인식합니다.

## 기계보다 사람이 더 중요하다

Bluefin의 모든 [아트워크](/artwork)는 작업에 대한 보상을 받은 사람이 만들 것입니다.
