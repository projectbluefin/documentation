Dakota Alpha 6 is out. This one is brought to you by [Ahmed Ahdan](https://github.com/ahmedadan)/ Built against GNOME 51 and freedesktop-sdk 26.08.1, running Linux 7.2.6, NVIDIA 615.71.09. Kernel OGC 7.2.6-ogc1 for your gaming needs.

This one certainly feels good! Please remember that we still do NOT support secure boot, so temper your expectations! Here's the changelog, I'll make a video on this one since we have a lot to discuss!

## Version matrix

Alpha 5 baseline values are from tag `stable-20260731` (as reflected in the Alpha 5 release announcement):

| Component          | Alpha 5           | Alpha 6           | Source / Pin                                 |
| ------------------ | ----------------- | ----------------- | -------------------------------------------- |

| Mutter             | `50.3`            | `51.0`            | `gnome-build-meta`                           |
| freedesktop-sdk    | `25.08.14`        | `26.08.1`         | `elements/freedesktop-sdk.bst`               |

| Kernel             | `7.0.11`          | `7.2.6`           | `elements/core/linux-fdsdk.bst`              |

| xdg-desktop-portal | `1.22.1`          | `1.22.1`          | `gnome-build-meta`                           |

_Note on kernel and bootc_: Dakota pins its kernel at `7.2.6` via `elements/core/linux-fdsdk.bst` (ahead of freedesktop-sdk 26.08.1's default of `7.2.2`) and pins bootc at `1.16.13` via `elements/gnomeos-deps/bootc.bst` (ahead of gnome-build-meta's default of `1.16.6`).

GNOME 51 "A Coruña" was officially released on September 16, 2026 — see the [official release notes](https://release.gnome.org/51/).

## Behavior changes

- Ghostty ships `resize-overlay = never`; theme tracks the GNOME Dark/Light preference.
- `snd_pcsp` sink disabled in WirePlumber — audio no longer falls back to the PC speaker after resume.
- zram is disabled; swap is zswap backed by `/var/swap/swapfile`.
- Bluetooth-Battery-Meter is replaced by BudsLink-Companion plus the `io.github.maniacx.BudsLink` Flatpak.
- `aarch64` images are not published this cycle. (We'll turn these on soon)
