A fresh Dakota Alpha arrives! Alpha 6 brings the latest upstream Dakota GNOME OS / bootc composefs image builds, installer stability updates, and refreshed unified ISO media.

## Highlights

- Fresh base built against current upstream Dakota GNOME OS & bootc composefs layers
- Unified live media supporting Intel/AMD and NVIDIA hardware from a single image
- Offline container storage embedding for rapid deployment without requiring live network pulls
- Fully automated plain and encrypted install paths verified in CI
